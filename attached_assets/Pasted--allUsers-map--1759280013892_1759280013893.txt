검증 시나리오 & 성공 기준

S1. 사용자 목록 표시

재현: 관리자 패널 > 사용자 관리 탭 접속

기대: 6개 사용자 표시

예: kksnan, mccnet02, mccnet01, DEV_FINAL_TEST_0923, mcclg02, mcctest01

성공 조건: 테이블 행 수 6개

S2. 서버 응답 일치

재현: Network 탭에서 /api/admin/admins 응답 확인

기대: HTTP 200, payload에 6명

성공 조건: 브라우저 표시 수와 서버 응답 수 일치, 콘솔 오류 0

S3. 중복 생성 방지 확인

재현: 기존 아이디(mccnet01 등)로 생성 시도

기대: “이미 사용 중인 아이디입니다” 메시지

성공 조건: 409/400 등 적절한 에러 및 UI 토스트 노출, 기존 레코드 불변

S4. 운영 동일 재현

절차: 테스트페이지 통과 후 운영(mccnetworld.com)에서도 S1~S3 반복

성공 조건: 결과 동일(6명 표시, 200 OK, 콘솔 오류 0)
