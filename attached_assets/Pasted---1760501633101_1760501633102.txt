2) 백엔드 API (단건 조회)
- GET /api/contact-codes/by-code?carrier=…&code=…
  - carrier: 선택된 통신사 키 (필수)
  - code: ‘전체 코드 문자열(접두어+숫자)’ 또는 ‘숫자 뒤자리’ 중 하나
  - 동작:
    - 서버에서 carrier별 접두어 테이블을 참조하여 최종 full_code를 구성
    - 정확 일치 단건 SELECT 후 {id, code, name, carrier, …} 반환 (없으면 404/204)
- 보안/검증:
  - carrier 없는 요청은 400
  - code 길이/패턴 검증(숫자 5~6자 등) 실패 시 422
