검증 시나리오 & 성공 기준
S1. 엑셀 업로드 (요금제 관리)

재현: 관리자 패널 > 요금제 관리 > 엑셀 업로드 → 파일 선택 → 업로드

성공 기준:

HTTP 200 OK

토스트: “성공적으로 업로드되었습니다”

서버 로그: Settlement pricing Excel upload completed

콘솔 에러 0

S2. 요금제 생성

재현: 서비스 플랜 > 추가 → 폼 입력 → 생성

성공 기준:

HTTP 200/201

토스트: “요금제가 성공적으로 생성되었습니다”

테이블에 신규 행 추가, DB service_plans INSERT 확인

S3. 사용자 삭제

재현: 사용자 관리 > 대상 사용자 → 삭제 → 확인

성공 기준:

HTTP 200 (FK 제약 시 409 명시적)

토스트: “사용자가 삭제되었습니다”

테이블에서 행 제거, DB users DELETE 확인

공통 성공 조건
