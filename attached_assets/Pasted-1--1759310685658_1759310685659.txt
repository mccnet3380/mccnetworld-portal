대시보드에 상단 통합 총 수량을 노출하고, 스크린샷의 **빨간 박스 위치(인터스티셜 영역)**에 현재 로그인한 관리자 개인의 개통 실적을 별도 카드로 표시.

2) 위치/명칭 정의 (오해 방지용 정확 표기)

페이지: /dashboard

구역 명칭:

상단 요약 섹션(Top Summary Section) = 통신사별 당월 개통현황 카드가 있는 상단 블록

컨트롤 바(Filter Toolbar) = 날짜 선택 + 실시간 업데이트 줄

인터스티셜 패널(Interstitial Panel) = 컨트롤 바 바로 아래 ~ 하단 KPI 섹션 바로 위의 빈 공간 ← 빨간 박스 위치

하단 KPI 섹션(Monthly KPI Board) = “당월 개통 현황(총 서류/대기/진행중/개통완료/기타완료/취소/폐기)” 타일들

요청 사항:

상단 요약 섹션 상단에 “총 수량” 카드 1개 추가

내용: “선택된 월의 총 서류 수(= 하단 KPI ‘총 서류’와 동일 수치)”

인터스티셜 패널(빨간 박스 위치)에 “관리자 개인 실적” 카드 1개 추가

내용: “오늘 개통 N건 · 당월 개통 M건 (로그인한 관리자 본인이 activated_by인 건만)”

UI/레이아웃/스타일/클래스/컴포넌트 구조는 절대 변경 금지. 기존 카드 컴포넌트 재사용으로 카드 “2개만” 추가.

6) 파일별 변경 이유 (각 1–2줄)

Dashboard.tsx: 상단 총 수량은 기존 월별 통계 API 응답에서 합계를 읽어 카드로 한 줄 추가. 인터스티셜 위치엔 관리자 개인 실적을 신규 API로 표시.

routes.ts: 관리자 로그인 세션에서 adminId를 추출, storage 호출 후 { todayCount, monthCount }로 응답.

storage.ts: activated_by = adminId + activation_status IN ('개통완료','기타완료') 기준으로 KST Today/Month 집계.

7) 데이터/응답 스펙 (명확히)
상단 “총 수량” 카드 (프론트만)

데이터 소스: 기존 /api/dashboard/monthly-activation-stats (이미 사용 중인 쿼리)

집계: 현재 컨트롤 바의 선택 월 기준, 하단 KPI ‘총 서류’와 동일 수치

프론트 처리: 기존 응답 배열 합계(total)를 카드에 표시 (백엔드 변경 없음)

인터스티셜 “관리자 개인 실적” 카드 (신규 API)

경로: GET /api/dashboard/admin-activation-stats (requireAdmin)

쿼리 파라미터: 없음 (서버가 세션에서 adminId 추출)

응답(JSON):

{ "todayCount": number, "monthCount": number }


정의:

todayCount: KST 오늘 00:00~24:00 범위, activated_at 기준, activation_status IN ('개통완료','기타완료'), activated_by = adminId

monthCount: KST 이번 달(date_trunc('month', ...)) 범위, 필터 동일

헤더: Cache-Control: no-store, Vary: Cookie

시간대: 모두 Asia/Seoul 기준. DB 비교는 KST 경계 → UTC로 변환하여 컬럼(activated_at) 비교.

8) 예상 변경 내용 (요약 diff · 개념)

storage.ts

getAdminActivationStats(adminId)

SQL(개념):

today: activated_at ∈ [KST 오늘 00:00, 24:00)

month: date_trunc('month', activated_at AT TIME ZONE 'Asia/Seoul') = date_trunc('month', now() AT TIME ZONE 'Asia/Seoul')

공통 WHERE: activated_by = :adminId AND activation_status IN ('개통완료','기타완료')

routes.ts

router.get('/api/dashboard/admin-activation-stats', requireAdmin, ...)

세션에서 adminId 추출 → storage 호출 → { todayCount, monthCount } 반환

Dashboard.tsx

기존 월별 쿼리 결과 합계로 “총 수량” 카드 추가(상단 요약 섹션 맨 위)

useQuery(['/api/dashboard/admin-activation-stats']) → **컨트롤 바 바로 아래(빨간 박스 위치)**에 카드 추가

스타일/클래스 기존 카드 그대로 재사용
