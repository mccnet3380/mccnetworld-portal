변경 개요

수정 목적:

처리자 매칭 오류(작업 완료 후 처리자명 미표시) 해결

실시간 업데이트 부재로 수량 미반영 문제 해결

필터링 중복(개통완료가 업무요청중에도 노출) 제거

대시보드 통계(근무자/관리자) 실시간·권한별 정확 표시

해결할 오류 / 재현 절차(간단)

처리자 매칭: 근무자 로그인 → 작업 완료 → 처리자명 - 또는 공백

실시간 업데이트: 상태 변경 후 새로고침 전까지 수량 미반영

필터링 오류: 접수관리 → 개통완료 선택 시, 업무요청중에도 동일 건 중복 노출

대시보드 수량: 근무자/관리자 권한별 통계가 즉시 반영되지 않음

변경 범위 요약

프론트엔드: 캐시 무효화(선택적), 목록 필터 로직, 통계 계산 로직, 처리자 표시 로직 보강

백엔드: 권한별 데이터 필터링/정렬 보강(응답 스키마 변경 없음)

client/src/pages/DocumentManagement.tsx — 상태별 문서 필터링 로직 수정(중복 제거)

client/src/pages/Dashboard.tsx — 관리자 통계 계산/표시 로직 개선(권한별 분기)

client/src/components/DealerDashboard.tsx — 근무자별 실시간 통계 반영(선택적 무효화)

server/routes.ts — 권한별 데이터 조회/필터 보강(응답 필드 유지)

파일별 변경 이유 (각 1–2줄)

DocumentManagement.tsx: “개통완료” 목록에서 activationStatus !== '업무요청중' 등 명확한 상태 필터로 중복 노출 제거.

Dashboard.tsx: userType(admin/worker)에 따른 권한별 통계 집계 분기 및 즉시 갱신.

DealerDashboard.tsx: 근무자 세션 기준 통계 계산 및 상태 변경 시 조건부 캐시 무효화 적용.

CompletedActivations.tsx: 세션 사용자/응답 내 이름 필드 기반 처리자명 폴백 체인 보강 + 저장/상태변경 성공 시 invalidateQueries 트리거.

server/routes.ts: 권한별(admin/worker) where 절 및 상태 필터 보강으로 응답 자체의 중복/누락 방지.
