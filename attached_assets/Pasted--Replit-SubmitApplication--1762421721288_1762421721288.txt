개발자용 프롬프트 (Replit에 전달)
목적

접수 신청(SubmitApplication) 화면 하단의 [추가 정보] 섹션을 제거하고,
접수 관리의 상태변경 모달에 있는 ‘작업 내용’ 입력 그룹과 동일한 필드를 하단에 그대로 배치하여
신규 접수 단계에서 바로 작업값(요금제/가입번호/유심번호 등)을 입력할 수 있게 합니다.

UI 레이아웃/스타일/클래스는 변경 금지(동일 컴포넌트/스타일 사용).

개발 서버(Neon)에서만 먼저 테스트/검증 → 확인 후 운영 서버에 반영.

수정 원칙(반드시 준수)

오류 부분만 최소 수정. UI 구조/스타일, Tailwind 클래스, 버튼/색상 변경 금지.

.env/Secrets/DB 연결/운영 DB 로직 변경 금지.

DB 스키마 변경 금지(필드 추가/삭제/마이그레이션 X).

가능하면 공용 컴포넌트화로 중복 최소화하되, 외형은 동일 유지.

파일 전체 최종본 제출(부분 코드 금지).

개발 서버에서만 테스트·검증 후 운영 적용.

변경 범위 요약

프론트엔드만, 1~2개 파일 중심 수정:

client/src/pages/SubmitApplication.tsx

(선택) client/src/components/WorkFields.tsx 신설해 재사용(모달과 동일 UI를 호출)

백엔드/빌드/배포/스키마/환경변수 변경 없음.

상세 작업 지시

[추가 정보] 섹션 제거

client/src/pages/SubmitApplication.tsx 에서 하단 카드(“추가 정보 / 메모”) 블록을 렌더링 제외 또는 삭제.

외형/여백 깨지지 않도록 기존 카드 컨테이너 레벨은 유지하되 내부 콘텐츠만 교체해도 됨.

‘작업 내용’ 입력 그룹 삽입 (모달과 완전 동일)

동일한 필드/순서/라벨/플레이스홀더 유지:

요금제 선택(검색형, servicePlanId)

가입번호(subscriptionNumber)

단말기기종(deviceModel)

유심번호(simNumber)

가입비 라디오(선납/후납/분납) → 기존 모달과 같은 값/키 사용

유심비 라디오(선납/후납) → 같은 값/키

결합 체크(결합/미결합) → 같은 값/키

업무 메모(workMemo)

보완 메모(secureMemo)

딜러 메모(dealerMemo)

검증/필수 여부는 모달과 동일 동작(없다면 모두 선택/입력 선택적).

스타일·간격·컴포넌트 계층은 모달과 동일하게 매칭.

중복 제거(선택 사항, 권장)

모달에 있는 ‘작업 내용’ 섹션 JSX를 <WorkFields /> 공용 컴포넌트로 분리
(client/src/components/WorkFields.tsx 등) 후:

상태변경 모달(기존 파일)과

SubmitApplication.tsx 모두에서 같은 컴포넌트 호출로 사용.

프롭스: value, onChange, disabled(옵션), servicePlans(선택 목록) 정도로 최소화.
필드 키는 현재 문서 도메인과 동일하게 유지(예: subscriptionNumber, simNumber 등).

저장 동작

신규 접수 저장 시, 위 ‘작업 내용’ 값들을 기존 POST 바디에 그대로 포함하여 전송.

백엔드 스키마/로직 변경 없이 해당 필드가 이미 허용되는 범위 내에서만 전송.

값이 비어있을 경우 **빈 문자열/null**로 안전 처리(에러 유발 X).

리스크와 회피책

리스크: 모달/신규 페이지 간 필드 정의가 엇갈리면 값 불일치 가능.

회피: 공용 컴포넌트로 필드/라벨/검증 로직을 단일화. 키 네이밍은 모달과 동일 유지.

롤백 계획

수정 전 SubmitApplication.tsx(및 새 WorkFields.tsx 생성 시 해당 파일) 백업.

문제 발생 시 해당 파일 원복 후 서버 재시작.

검증 시나리오 & 성공 기준 (개발 서버에서만)

신규 접수 작성

접수 신청 페이지 하단에 ‘작업 내용’ 입력군 노출, [추가 정보]는 사라짐.

요금제/가입번호/유심번호 등 입력 후 저장 → 200 응답, 목록/상세에서 값 반영.

상태변경 모달과 UI 일치성

모달의 ‘작업 내용’과 라벨/순서/동작 동일(라디오/체크/검색형 셀렉트 포함).

회귀

기존 접수 생성/조회/엑셀 다운로드 등 기능 이상 없음.
