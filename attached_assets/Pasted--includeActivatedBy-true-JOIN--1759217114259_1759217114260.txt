수정 목적(한 줄)

기타완료 문서 목록에서 처리자명이 “-”로 표시되는 문제를, includeActivatedBy=true 조건부 JOIN과 프론트 파라미터 추가만으로 복구.

해결할 오류 / 재현 절차(간단)

오류 증상: 관리자 로그인 → “기타완료” 진입 → 처리자 컬럼이 “-”

원인: 해당 페이지의 API 호출에 includeActivatedBy=true 누락 → 백엔드 기본 쿼리에 users JOIN 미포함

비교:

✅ 완료 관리(CompletedActivations): includeActivatedBy=true 전달 → 처리자 정상 표시

❌ 기타완료(OtherCompletions): 파라미터 누락 → 처리자 표시 안 됨

기대 결과: 기타완료 페이지에서도 처리자명이 정상 표시되고, 네트워크 응답에 activatedByName 포함(200 OK, 콘솔 오류 0).

변경 범위 요약

백엔드(최소): server/storage.ts 내 getDocuments()에 조건부 JOIN 로직 추가 (이미 다른 화면에서 사용 중인 패턴 준용)

프론트엔드(최소): client/src/pages/OtherCompletions.tsx에서 API 호출 시 includeActivatedBy=true 파라미터 추가

빌드/배포: 프론트 빌드, 서버 재시작 필요

불변 명시: 환경설정(.env/Secrets/DB 연결/운영 DB 로직) 미변경, DB 스키마 미변경, UI(레이아웃/디자인/스타일/컴포넌트 구조) 미변경
